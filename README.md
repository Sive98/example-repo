# Financial Calculators

## Project Description
This project contains Python financial calculators developed as part of my HyperionDev software development bootcamp.

The program performs financial calculations based on user input. It demonstrates Python fundamentals, including variables, user input, calculations, and conditional logic.

## How to Run
1. Make sure Python is installed.
2. Open a terminal in this project folder.
3. Run:

python financial_calculators.py
